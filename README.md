# 🤖 CodeAlpha Basic Chatbot

A simple yet interactive **rule-based chatbot** developed using **Python** as part of the **CodeAlpha Python Programming Internship (Task 4 – Basic Chatbot)**. The chatbot interacts with users through predefined commands and provides useful responses such as greetings, current date & time, jokes, motivational quotes, simple calculations, and a number guessing game.

## 📖 Project Overview

The **Basic Chatbot** is a console-based Python application that simulates a simple conversation with users using predefined rules. Unlike AI-powered chatbots, this chatbot responds using conditional statements (`if-elif-else`) and functions.

The chatbot also includes additional interactive features such as:

- Personalized greeting
- Calculator
- Date & Time display
- Programming jokes
- Motivational quotes
- Number guessing game

This project demonstrates Python programming fundamentals while creating an engaging user experience.

---

## ✨ Features

- 👋 Greets users based on the current time
- 😊 Remembers the user's name during the session

## 💻 Available Commands

| User Command | Bot Response |
|--------------|--------------|
| hello / hi / hey | Greets the user |
| how are you | Replies politely |
| your name | Displays chatbot name |
| date | Shows today's date |
| time | Shows current time |
| calculate | Opens the calculator |
| joke | Displays a random programming joke |
| motivate | Displays a motivational quote |
| guess | Starts the number guessing game |
| thanks | Replies politely |
| help | Shows all available commands |
| bye | Ends the conversation |
